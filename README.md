# Rate Repository

Full Stack Open Part 10 application built with Expo SDK 55, React Native and Expo Router.

Lists repositories with a reusable item component, a scrollable app bar, and a validated sign-in form built with Formik and Yup. Text uses Roboto on Android and Arial on iOS.

## Local setup

Use Node 24 and install dependencies with `npm ci`. Run `npm start` and open the project with Expo Go or an emulator. `npm run web` provides a browser preview.

## Checks

- `npm run lint`
- `npm run typecheck`
